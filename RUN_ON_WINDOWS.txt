GREENPOD LABS ASSIGNMENT 2 — ORANGE DATASET PACKAGE
==================================================

IMPORTANT:
The Google Drive ZIP you provided contains orange classes:
blackspot, canker, fresh, grenning.
It is not an avocado ripening dataset. This project matches the data actually supplied.
Please confirm the mismatch with GreenPod Labs before submitting it as an avocado assignment.

1. Extract this ZIP.
2. Open PowerShell in the extracted project folder.
3. Create an environment and install dependencies:

   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install --upgrade pip
   pip install -r requirements.txt

4. Run EDA:
   python src/01_eda.py

5. Prepare train/validation/test:
   python src/02_split_dataset.py

6. Train classical SVM:
   python src/03_train_classical.py

7. Train MobileNetV2 (internet required on first run to download ImageNet weights):
   python src/04_train_mobilenet.py --epochs 12 --batch_size 16

8. Demo both trained models with a real image path, e.g.:
   python src/05_demo.py --image "data/split/test/fresh/REPLACE_WITH_REAL_FILENAME.jpg"

Outputs go into outputs/eda, outputs/classical and outputs/mobilenet.
Actual MobileNet metrics must be generated by running step 7 on your machine.
